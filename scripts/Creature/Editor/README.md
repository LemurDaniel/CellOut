# Creature/Editor

The full screen creature editor, from the organism stage on. Uses `Cell/Editor/PartGizmo.cs` and `Game/Ui/EditorStyle.cs`.

| File | Content |
| --- | --- |
| `CreatureEditor.cs` | Type choice (fish or marine mammal), then sculpting the clay on a turntable: vertebra handles, + / - vertebrae, symmetry switch, category tabs with part tiles dragged onto the clay, live stats column (weight, carry, land speed, flight). |
