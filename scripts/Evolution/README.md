# Evolution

Rules of the cell and creature editors and the diet, no nodes.

| File | Content |
| --- | --- |
| `PartCatalog.cs` | Every editor part: diet class, cost, placement, unlock range. |
| `CellDesign.cs` | Placed parts of a cell (every cell of the cluster carries them), placement rules. |
| `DietTracker.cs` | Plant vs. meat meals, fading, mixed with the part lean. |
| `CreatureCatalog.cs` | Every creature part: cost, mount (tail, head, back, flanks), body type (fish, marine mammal). |
| `CreatureDesign.cs` | Body plan of an organism: spine girths, placed parts, geometry (profile, inside test), NPC plans. |
