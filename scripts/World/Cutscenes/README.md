# World/Cutscenes

Animations that run while the game is paused, Main frees them when they are done.

| File | Content |
| --- | --- |
| `Intro.cs` | Start animation: molecules swirl together, a membrane closes, the protocell is born. |
| `EvolveCutscene.cs` | 64 cells divide on to 512, curl up into a hollow ball and melt into a clay blob. |
