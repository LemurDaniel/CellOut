# Scripts

C# sources of Cell Out (namespace `CellOut`), one class per file, file name = class name (Godot requirement).

| Folder | Content |
| --- | --- |
| `Core/` | Helpers without game rules: 2D↔3D bridge, random, verbose log. |
| `Cells/` | Player, NPC cells and their 3D bodies. |
| `Evolution/` | Editor rules: part catalog, cell design, diet tracker. |
| `World/` | Game loop (`Main`), food, scenery and effects. |
| `Ui/` | HUD, cell editor and the diet bar. |
