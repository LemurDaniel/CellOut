# Tribe/Building/Editor/Views

The panels of the village builder. They report clicks through C# events, the `BuildingEditor` acts on them.

| File | Content |
| --- | --- |
| `BuildingPalette.cs` | The group icons, below them the blocks of the group shown in two scrolling columns of tiles with a live 3D icon and the name. |
| `BlockIcon.cs` | The live 3D icon of one block. |
| `BuildingSidebar.cs` | Cost and effect of the function shown, the drop-down menu "Templates" and the paint menu (pattern and paint swatches). |
