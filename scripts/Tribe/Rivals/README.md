# Tribe/Rivals

The neighbor tribes of the player's tribe.

| File | Content |
| --- | --- |
| `RivalKeeper.cs` | Component of `Main`: settles the rivals when the tribe is founded (one on the own island, the others on the next islands), friendly ones send traders, hostile ones raids, resolves every fight between factions and the raiders at the huts, gifts, relation drift. |
| `RivalTribe.cs` | One neighbor tribe: fire, buildings from random templates (dwellings and one the tribe is known for), villagers, its relation to the player, its traders and raiders. |
